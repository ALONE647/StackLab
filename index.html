Why a stack?

THE CORE IDEA

A stack follows LIFO: the newest item is always the first one out. Think browser history, undo actions, or the call stack keeping track of functions.

Stack operations

A stack only lets you interact with its top. That keeps each core operation constant time.

push(value)  → add value to top
+pop()        → remove and return top
+peek()       → read top without removing
+isEmpty()    → check whether size is 0
+
+overflow    → push when capacity is full
+underflow   → pop or peek when empty
